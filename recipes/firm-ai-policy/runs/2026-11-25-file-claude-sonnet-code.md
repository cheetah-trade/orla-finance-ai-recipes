## 3. Client data that never goes into an AI tool

| What | What to do | Why |
|---|---|---|
| Social Security numbers, tax ids (TIN, EIN) | Remove | Identifies a person or business |
| Full bank account and card numbers | Keep last four digits | Enough to match, not to misuse |
| Home addresses, dates of birth | Remove | Identifies an individual |
| Names of private persons the task does not need | Replace with a label; keep the label list outside the tool | Limits who is identifiable |
| Pay by person, health or family details (payroll, Q3) | Remove; use totals if needed | Sensitive personal data |
| Individual and business tax return contents (Q3) | Remove ids, names and addresses first | Returns hold the fields above |
| Scans of passports, ID cards, signed tax forms | Never upload | Cannot be masked |
| Passwords, login codes, licence keys | Never paste | Gives access to others |
| Notes about suspected wrongdoing by a client | Never put into an AI tool | Harm if exposed |
| File names and document properties | Rename the file and clear properties before upload | They can name the client |
| Rare amount with its date | Treat as identifying | Masking makes data smaller, not anonymous |
